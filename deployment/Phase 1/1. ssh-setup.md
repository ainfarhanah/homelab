# Setup SSH

## To check SSH status

```bash
sudo systemctl status ssh
sudo apt update
```
Since there's no SSH service installed, here we go install the SSH service

```bash
sudo apt install openssh-server -y
```
Enable the SSH service
```bash
sudo systemctl start ssh
sudo systemctl enable ssh
```
Check IP device
```bash
ip a
```
Check firewall status
```bash
sudo ufw status
```
To allow firewall to permit incoming connections on SSH
```bash
sudo ufw allow ssh
sudo ufw enable
```
Restart SSH service
```bash
sudo systemctl restart ssh
```
