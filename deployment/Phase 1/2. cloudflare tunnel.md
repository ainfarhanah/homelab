## Cloudflared Tunnel Service Setup

This section covers the installation and setup of the `cloudflared` daemon to create a Zero Trust Tunnel for secure remote access.

### Cloudflared Installation Attempts

The following records show various attempts to install `cloudflared`, likely to find the correct method for the operating system (combining `yum` and `apt` steps).

#### Debian/Ubuntu (APT) Method:

```bash
# Add Cloudflare GPG key
curl -fsSL [https://pkg.cloudflare.com/cloudflare-main.gpg](https://pkg.cloudflare.com/cloudflare-main.gpg) | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
# Update package list and install
sudo apt update
sudo apt install cloudflared
# OR Installation via downloaded DEB file
wget [https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb](https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb)
sudo apt install ./cloudflared-linux-amd64.deb
```

#### Install and Manage Service
Once the binary was installed, the service was set up, enabled, and started.
```bash
# Install the tunnel as a system service (using UUID and Token)
sudo cloudflared service install eyJhIjoiNTdiZWUyZTIwNDYwYjgyYzNhY2FhMDFjYzM5NWQzZjkiLCJ0IjoiMTI2YzM0...

# Tell systemd to reload configuration (must be run after creating/editing service files)
sudo systemctl daemon-reload

# Enable the service to start on boot
sudo systemctl enable cloudflared

# Start the service immediately
sudo systemctl start cloudflared

# Check the service status
sudo systemctl status cloudflared
```
## Secure Remote Access (SSH and Cloudflare Tunnel Configuration)
This section documents the configuration steps for accessing the server via ssh.hanaxxiv-server.site using the Cloudflare Tunnel.

#### Local SSH Key Generation

A new Ed25519 SSH key was generated on the client machine.

```bash
ssh-keygen -t ed25519 -C "hannah@homelab"
```

#### Deploying the Public Key
The public key was copied to the remote server to enable key-based login.
```bash
ssh-copy-id hannah@ssh.hanaxxiv-server.site
```

#### Cloudflare Tunnel Routing
These commands associate the public hostname with the running tunnel and configure the local service destination.
```bash
# 1. Route the public DNS hostname to the 'homelab' tunnel
cloudflared tunnel route dns homelab ssh.hanaxxiv-server.site

# 2. Command used to run/test the tunnel (for the SSH service on port 22)
cloudflared tunnel run homelab --url ssh://localhost:22
```
