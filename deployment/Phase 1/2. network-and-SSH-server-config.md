# Initial System Network Check
To check the server is correctly updated

```bash
sudo apt update
```

To check the server IP
```bash
ip a
```

To check the server hostname
```bash
hostnamectl
```

Successful refresh
```bash
sudo apt update
```

## SSH server configuration
I first checked the status of the SSH server
```bash
sudo systemctl status ssh
```
Since the SSH is not installed, I installed via apt
```bash
sudo apt install openssh-server -y
```
Start the SSH server
```bash
sudo systemctl start ssh
```
Enable the SSH server to start at boot
```bash
sudo systemctl enable ssh
```
Check the status of the SSH server
```bash
sudo systemctl status ssh
```

Also allowed the SSH port in the firewall
```bash
sudo ufw allow ssh
```
Enabled the firewall
```bash
sudo ufw enable
```
Check the status of the firewall
```bash
sudo ufw status
```
Restart the SSH server
```bash
sudo systemctl restart ssh
```
Check the status of the SSH server
```bash
sudo systemctl status ssh
```
Since the SSH enabled, I can connect to the server using MobaXterm or any other SSH client and device connected to the same network
