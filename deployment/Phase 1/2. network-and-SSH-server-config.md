# SSH server configuration and secure remote access Ubuntu

## 1. Initial system network check
Update package list:

```bash
sudo apt update
```

To check the server IP
```bash
ip a
```

To check the server hostname
```bash
hostnamectl
```

Successful refresh
```bash
sudo apt update
```

## 2. SSH server configuration
Check the status of the SSH server
```bash
sudo systemctl status ssh
```
Since the SSH is not installed, I installed via apt
```bash
sudo apt install openssh-server -y
```
Start the SSH server
```bash
sudo systemctl start ssh
```
Enable the SSH server to start automatically on boot
```bash
sudo systemctl enable ssh
```
Check the status of the SSH server
```bash
sudo systemctl status ssh
```
## 3. Firewall configuration (UFW)
Also allow the SSH port in the firewall
```bash
sudo ufw allow ssh
```
Enable the firewall
```bash
sudo ufw enable
```
Check the status of the firewall
```bash
sudo ufw status
```
Restart the SSH server to apply changes
```bash
sudo systemctl restart ssh
```
Check the status of the SSH server
```bash
sudo systemctl status ssh
```

## 5. Remote Key-Based Authentication (Recommended)
Generate SSH key on client
```bash
ssh-keygen -t ed25519
```
Copy the public key to the server
```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@server_ip
```
Connect to the server using SSH with key
```bash
ssh user@server_ip
```

## 6. Custom SSH Port Configuration
I used a custom port for SSH connection to make it more secure.

Allow the port ```2222``` in the firewall
```bash
sudo ufw allow 2222/tcp
```
Restart the SSH service
```bash
sudo systemctl restart ssh
```
Check the status of the SSH service
```bash
sudo systemctl status ssh
```
